\# Java Practice Programs



A structured collection of Java practice programs covering core Java concepts, algorithms, data structures, and console-based mini projects.



This repository demonstrates learning and practice in:

\- Java fundamentals

\- Loops, conditionals, and methods

\- Arrays and matrix operations

\- String manipulation

\- Recursion

\- Sorting algorithms

\- Number system conversions

\- Exception handling

\- Menu-driven programs

\- Mini console projects



Programs are organized by topic for clarity and progressive learning.



\## Featured Programs



Some of the more interesting programs in this repository:



\- Tic Tac Toe (Mini Projects / Console Games)

\- Number Guessing Game

\- Matrix Sorting Programs

\- String Duplicate Removal

\- Smith Number Checker

\- Number System Conversions
